Case Study

苏瑾 · 三阶段拟人剧情

同一套核心引擎，换上 SujinMapper，即可演绎一个从低信任到共创、再到背叛后缓慢修复的人物弧光。

PHASE 01 · 低信任严谨

戒备中的专业

信任容量低，对批评敏感、对夸奖保留。预期落空会放大负面情绪，自尊在反复试探中轻微动摇。

PHASE 02 · 高信任共创

默契与心流

经过睡眠的梦境加工与预期兑现，信任上升、心境转暖、自尊达到高位，进入高效共创状态。

PHASE 03 · 背叛与修复

羞耻、崩塌与缓慢愈合

背叛触发羞耻维度与自尊崩塌，防御层级启动；认知失调在睡眠中逐步合理化，长期愈合但 max_trust 永久降低。

Quick Start

30 行跑起来

纯 Python，零依赖。核心不认识任何事件名，所有语义由外部映射器注入。

from SPL_anthropic_engine import SPLPureCoreV7_3 # 创建核心（类名 V7_3 为兼容命名，内部即 V8.0 通用心理架构） core = SPLPureCoreV7_3(psychological_resilience=0.4) core.set_clock(0.0) # 注入内感受向量（语义无关）：威胁 / 归属 / 自主 / 疲劳 / 羞耻触发 core.process_vector({"threat": 0.5, "belonging": -0.6}, intensity=1.0) # 设定对未来的预期，随后兑现 → 惊喜 / 落空 → 失望 core.expect("sign_contract", valence=0.6, confidence=0.7) # 睡眠：梦境加工情绪、消退恐惧、偿还睡眠债 core.sleep(hours=8) # 认知失调：信念冲突 → 张力 → 自动合理化消解 core.induce_dissonance(magnitude=0.5, belief_domain="loyalty") # 读取完整心理快照 snap = core.snapshot() print(snap["fluid"], snap["mood"], snap["self_esteem"])
