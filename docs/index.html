Psychological Subsystems

V8.0 通用心理构成

V8.0 Universal Psychology

以下七项并非角色自设，而是所有人类共有的心理架构，已写入核心引擎。

The following seven are not character self-settings but the psychological architecture shared by all humans, written into the core engine.

🌊

8 维情绪流体

8-Dim Emotion Fluids

喜悦 · 愤怒 · 恐惧 · 信任 · 疏离 · 张力 · 愧疚 · 羞耻。各维以自适应粘滞度向动态目标松弛，构成瞬时情绪。

Joy · Anger · Fear · Trust · Detachment · Tension · Guilt · Shame. Each dimension relaxes toward a dynamic target with adaptive viscosity, forming instantaneous emotion.

动态粘滞 Dynamic Viscosity 情绪反馈 Emotion Feedback
🌗

心境层 Mood

Mood Layer

慢变量背景情绪（愉悦 / 紧张 / 精力），惯性极大（约 1 小时半衰期），持续调制认知评估的增益。

Slow-variable background emotion (Pleasure / Tension / Energy) with huge inertia (~1-hour half-life) continuously modulating the gain of cognitive appraisal.

慢变量 Slow Variable Russell 环状 Russell Circumplex
🪞

自尊动态 Self-Esteem

Self-Esteem Dynamics

自尊 [0,1] 随事件缓慢修正；低自尊者把失败内归因、放大威胁感——决定"我值多少"的自我感知。

Self-esteem [0,1] slowly revised by events; low self-esteem internalizes failure and amplifies threat — the self-perception of "how much I'm worth".

归因偏差 Attribution Bias Rosenberg
🌙

睡眠 / 梦境加工

Sleep / Dream Processing

sleep(hours) 不仅恢复精力，更在"梦境"中衰减情绪电荷、实现恐惧消退——真正的"睡一觉就好"。

sleep(hours) not only restores energy but also decays emotional charge in "dreams" and achieves fear extinction — a real "sleep it off".

REM 加工 REM Processing 睡眠债 Sleep Debt
🔭

预期系统 Anticipation

Anticipation

expect() 设定对未来的积极/威胁预期；事件兑现产生惊喜，落空产生失望——让 Agent 为未来而感受。

expect() sets positive/threat expectations about the future; fulfillment brings surprise, miss brings disappointment — letting the agent feel for the future.

希望 Hope 焦虑 Anxiety 失望 Disappointment
⚖️

认知失调 Dissonance

Cognitive Dissonance

信念与行为冲突时产生失调张力，超过阈值后自动通过"合理化"消解——Festinger 经典的自我辩护引擎。

When belief conflicts with behavior, dissonance tension arises; beyond a threshold it auto-resolves via "rationalization" — Festinger's classic self-justification engine.

合理化 Rationalization Festinger
🛡️

防御机制层级

Defense Mechanism Hierarchy

否认 → 合理化 → 压抑，逐级递进。高压下先否认现实，失效则合理化，再失效则压抑入隐压池等待反弹。

Denial → Rationalization → Repression, escalating. Under high pressure deny reality first; if that fails, rationalize; if that fails, repress into the latent pool awaiting rebound.

否认 Denial 置换 Displacement 压抑 Repression
Case Study

苏瑾 · 三阶段拟人剧情

Sujin · Three-Phase Anthropomorphic Arc

同一套核心引擎，换上 SujinMapper，即可演绎一个从低信任到共创、再到背叛后缓慢修复的人物弧光。

The same core engine, swapped with SujinMapper, can play out an arc from low trust to co-creation, then slow repair after betrayal.

PHASE 01 · 低信任严谨 · Low-Trust Rigor

戒备中的专业

Professionalism in Guardedness

信任容量低，对批评敏感、对夸奖保留。预期落空会放大负面情绪，自尊在反复试探中轻微动摇。

Low trust capacity, sensitive to criticism, reserved about praise. Unmet expectations amplify negative emotion; self-esteem wavers slightly through repeated probing.

PHASE 02 · 高信任共创 · High-Trust Co-creation

默契与心流

Tacit Understanding & Flow

经过睡眠的梦境加工与预期兑现，信任上升、心境转暖、自尊达到高位，进入高效共创状态。

After dream processing during sleep and expectation fulfillment, trust rises, mood warms, self-esteem peaks — entering efficient co-creation.

PHASE 03 · 背叛与修复 · Betrayal & Repair

羞耻、崩塌与缓慢愈合

Shame, Collapse & Slow Healing

背叛触发羞耻维度与自尊崩塌，防御层级启动；认知失调在睡眠中逐步合理化，长期愈合但 max_trust 永久降低。

Betrayal triggers the shame dimension and self-esteem collapse; defense layers activate; cognitive dissonance gradually rationalizes during sleep — long-term healing but max_trust permanently lowered.

Quick Start

30 行跑起来

Running in 30 Lines

纯 Python，零依赖。核心不认识任何事件名，所有语义由外部映射器注入。

Pure Python, zero dependencies. The core knows no event names; all semantics are injected by external mappers.

from SPL_anthropic_engine import SPLPureCoreV7_3 # 创建核心（类名 V7_3 为兼容命名，内部即 V8.0 通用心理架构） # Build the core (class name V7_3 is a compatibility alias; internally V8.0) core = SPLPureCoreV7_3(psychological_resilience=0.4) core.set_clock(0.0) # 注入内感受向量（语义无关）：威胁 / 归属 / 自主 / 疲劳 / 羞耻触发 # Inject interoceptive vector (semantics-agnostic): threat / belonging / autonomy / fatigue / shame core.process_vector({"threat": 0.5, "belonging": -0.6}, intensity=1.0) # 设定对未来的预期，随后兑现 → 惊喜 / 落空 → 失望 # Set an expectation, then fulfill → surprise / miss → disappointment core.expect("sign_contract", valence=0.6, confidence=0.7) # 睡眠：梦境加工情绪、消退恐惧、偿还睡眠债 # Sleep: dream-process emotion, extinguish fear, repay sleep debt core.sleep(hours=8) # 认知失调：信念冲突 → 张力 → 自动合理化消解 # Cognitive dissonance: belief conflict → tension → auto rationalization core.induce_dissonance(magnitude=0.5, belief_domain="loyalty") # 读取完整心理快照 # Read the full psychological snapshot snap = core.snapshot() print(snap["fluid"], snap["mood"], snap["self_esteem"])
