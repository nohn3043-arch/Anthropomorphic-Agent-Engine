Case Study

Sujin · Three-Phase Anthropomorphic Arc

The same core engine, swapped with SujinMapper, can play out an arc from low trust to co-creation, then slow repair after betrayal.

PHASE 01 · Low-Trust Rigor

Professionalism in Guardedness

Low trust capacity, sensitive to criticism, reserved about praise. Unmet expectations amplify negative emotion; self-esteem wavers slightly through repeated probing.

PHASE 02 · High-Trust Co-creation

Tacit Understanding & Flow

After dream processing during sleep and expectation fulfillment, trust rises, mood warms, self-esteem peaks — entering efficient co-creation.

PHASE 03 · Betrayal & Repair

Shame, Collapse & Slow Healing

Betrayal triggers the shame dimension and self-esteem collapse; defense layers activate; cognitive dissonance gradually rationalizes during sleep — long-term healing but max_trust permanently lowered.

Quick Start

Running in 30 Lines

Pure Python, zero dependencies. The core knows no event names; all semantics are injected by external mappers.

from SPL_anthropic_engine import SPLPureCoreV7_3 # Build the core (class name V7_3 is a compatibility alias; internally it is the V8.0 universal psychology) core = SPLPureCoreV7_3(psychological_resilience=0.4) core.set_clock(0.0) # Inject interoceptive vector (semantics-agnostic): threat / belonging / autonomy / fatigue / shame_trigger core.process_vector({"threat": 0.5, "belonging": -0.6}, intensity=1.0) # Set an expectation about the future, then fulfill it → surprise / miss → disappointment core.expect("sign_contract", valence=0.6, confidence=0.7) # Sleep: dream-process emotion, extinguish fear, repay sleep debt core.sleep(hours=8) # Cognitive dissonance: belief conflict → tension → auto rationalization core.induce_dissonance(magnitude=0.5, belief_domain="loyalty") # Read the full psychological snapshot snap = core.snapshot() print(snap["fluid"], snap["mood"], snap["self_esteem"])
